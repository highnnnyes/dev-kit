`$ARGUMENTS`의 첫 단어로 모드를 고른다: `backfill` | `portfolio`.
없으면 두 모드를 설명하고 어느 쪽인지 묻는다.

모든 프로젝트는 사용자의 포트폴리오다 — 사용자가 입력하고 판단하고 결정한
것이 남아야 한다. 저널 형식·출처 태그는 docs 스킬 "결정 저널"을 따른다
(이 커맨드가 형식을 재정의하지 않는다).

## backfill — 과거 결정 초안 → 일괄 확인 → 저장

1. **조사 (읽기 전용)** — 아래 소스에서 주요 결정을 뽑는다. 이 단계에서
   파일을 수정하지 않는다:
   - `git log` (커밋 제목·본문 — 특히 방향 전환·되돌림·"사용자 결정/지시/
     정정" 언급)
   - `CHANGELOG.md`, `PROGRESS.md` + `PROGRESS.archive.md` (DECISIONS·
     BLOCKED·사용자 결정 줄), `docs/decisions/` (ADR), `DESIGN.md`의
     기각한 대안, `docs/diagnosis-*.md`
   - "주요"의 기준: 방향이 바뀐 결정, 기각안이 있었던 결정, 사고와 그 대응,
     실측·실험으로 바뀐 결정. 태스크 단위 구현 선택은 넣지 않는다.
2. **초안** — 항목마다 docs 스킬 형식(날짜/상황/내 입력/선택지/결정+이유/
   출처/근거/설명 포인트)을 채운다. **출처 태그 판정 [엄격]**:
   - 소스에 사용자 발화·지시가 **원문으로** 남아 있고 그것이 결정을 먼저
     제시했으면 `[내 판단]` 후보, AI가 제안하고 사용자가 승인한 기록이
     있으면 `[AI 제안→내가 채택]` 후보, 사용자 관여 기록이 없는 AI 결정이면
     `[AI 자율]` 후보.
   - **소스로 확인할 수 없으면 `[출처 미확인]`**. 추측해서 태그를 달지
     않는다 — "아마 사용자가 정했을 것"은 확인이 아니다.
   - `내 입력` 칸은 원문이 있을 때만 채운다. 없으면 `(기록 없음)`.
3. **일괄 확인 [엄격]** — 저장 전에 사용자에게 **표 하나로** 묻는다:
   `| # | 날짜 | 결정 요지 | 초안 태그 | 근거 소스 |` — `[출처 미확인]` 행과
   초안 태그가 `[내 판단]`인 행(오기록 방지)을 모두 포함한다. 사용자의
   답으로 태그를 확정한다. 답이 없는 행은 `[출처 미확인]`으로 남기지 않고
   **저장하지 않는다** (미확정 항목은 보고에 목록으로).
4. **저장** — `docs/journal.md`에 시간순으로 넣는다. 기존 항목이 있으면
   수정하지 않고, 백필 항목은 기존 항목보다 앞 날짜라도 **파일 맨 앞의
   `## 백필 (YYYY-MM-DD 작성)` 섹션**에 모은다 (append-only 원칙 — 기존
   항목의 위치·내용을 바꾸지 않는다). 커밋: `[journal] backfill — N항목`.

## portfolio — journal → docs/portfolio.md 1장

1. `docs/journal.md`에서 출처가 `[내 판단]` 또는 `[AI 제안→내가 채택]`인
   항목만 추린다. `[AI 자율]`·`[출처 미확인]`은 넣지 않는다.
2. **1장 제한**: 프로젝트 한 줄 소개 + 항목 5~10개. 항목마다
   **문제 → 내 결정 → 결과(지표)** 3줄. 결과 칸은 journal 근거 칸의 지표·
   커밋에서만 가져온다 — 근거에 지표가 없으면 `결과: 측정 없음`으로 쓴다
   (지표를 만들어내지 않는다).
3. `[AI 제안→내가 채택]` 항목은 결정 줄에 "AI 제안 채택"을 명시하고, journal의
   설명 포인트("왜 이 설계인가")를 그대로 옮긴다 — 사용자가 면접에서
   설명할 수 있어야 하는 항목이다.
4. 저장: `docs/portfolio.md` (있으면 덮어쓴다 — journal에서 파생되는
   산출물이라 원본이 아니다). 커밋: `[journal] portfolio 갱신`.
